02 · Terminal

Levantar cada app

Las 3 apps salen del mismo código con distinto entry point. Dispositivo de prueba conocido: Samsung SM G781B, id RFCT416HY5K. Corre siempre desde D:\indrive_bolivia\indrive_app.

App Cliente (Android)

powershell
flutter run -d RFCT416HY5K -t lib\main_cliente.dart

App Repartidor (Android)

powershell
flutter run -d RFCT416HY5K -t lib\main_repartidor.dart

Panel Admin (Web / Chrome)

powershell
flutter run -d chrome -t lib\main_admin.dart

No se puede tener dos apps a la vez en el mismo celular. Cliente, Repartidor y Admin comparten el mismo applicationId (com.example.indrive_app) — instalar una sobrescribe a la otra. Para probar dos roles a la vez: usa un emulador Android además del celular físico, o pide la migración a product flavors (pendiente, ver Backlog).

Desde VS Code (sin recordar el comando)

El proyecto ya tiene .vscode/launch.json con 3 configuraciones nombradas. Abre el panel "Run and Debug", elige Cliente, Repartidor o Admin (Web) en el dropdown, elige el dispositivo abajo, y presiona F5.

Verificación rápida (sin dispositivo)

powershell
flutter pub get
flutter analyze
flutter test
03 · Backend

Firebase y Firestore

Proyecto indrive-entregas-villazon, plan Blaze, región southamerica-east1. Sesión de Firebase CLI activa como dagmcisco@gmail.com.

Desplegar reglas + índices de Firestore

powershell
firebase deploy --only firestore --project=indrive-entregas-villazon

Desplegar Cloud Functions

powershell
firebase deploy --only functions --project=indrive-entregas-villazon

Ver qué rol/verificación tiene cada cuenta

No hay UI para esto todavía (llega en el panel Admin). Mientras tanto, exporta los usuarios y mira customAttributes:

powershell
firebase auth:export usuarios.json --project=indrive-entregas-villazon --format=json
type usuarios.json

Ver logs de una Cloud Function

powershell
firebase functions:log --only assignInitialRole --project=indrive-entregas-villazon

Primer deploy de una función nueva puede fallar con "Cannot determine backend specification. Timeout after 10000" — es la primera vez que Eventarc propaga permisos, espera 2–3 minutos y vuelve a correr el mismo comando.

04 · Bootstrap manual

Scripts de administración

Dos acciones que hoy no tienen UI (llegan con el panel Admin) y se resuelven con scripts puntuales desde indrive_app/functions.

Paso previo, una sola vez: la clave de servicio

Ambos scripts necesitan functions/scripts/serviceAccountKey.json (gitignored, nunca se sube). Se genera en Firebase Console → Configuración del proyecto → Cuentas de servicio → Generar nueva clave privada, y se guarda con ese nombre exacto en esa carpeta.

Crear o promover un Admin

powershell · desde indrive_app/functions
npx ts-node scripts/setAdminClaim.ts <UID>

Marcar un Repartidor como verificado (KYC)

powershell · desde indrive_app/functions
npx ts-node scripts/setVerifiedClaim.ts <UID>

Nunca escribas <UID> literal. En PowerShell, < y > son símbolos reservados de redirección — copia el UID real desde Firebase Console → Authentication → clic en la fila del usuario.

06 · Cicatrices

Cosas que ya nos mordieron una vez

Errores reales que ya diagnosticamos — si vuelven a aparecer, la solución ya está probada.

01
Kotlin incremental roto en Windows

Falla si el proyecto y el pub-cache están en discos distintos (C: vs D:). Ya está desactivado en android/gradle.properties (kotlin.incremental=false) — no lo reactives.

02
Windows desktop no es una plataforma objetivo

Solo Android + Web. Cualquier error de Gradle/AGP corriendo -d windows es irrelevante, ignóralo.

03
Gradle no corre en el entorno de Claude

"Unable to establish loopback connection" — es una limitación del sandbox donde corre Claude, no del proyecto. Los builds de Android/Gradle los tienes que correr vos, en tu propia terminal.

04
El rol de un teléfono es para siempre

assignInitialRole rechaza reasignar rol a una cuenta que ya tiene uno. Para probar un rol nuevo, se necesita un número de teléfono de prueba nuevo.

05
flutter_local_notifications necesita .initialize()

Sin esa llamada, crear canales o mostrar notificaciones falla en silencio. Ya está corregido en FcmService.

06
La API key de Google Maps no se commitea

Vive en android/local.properties como MAPS_API_KEY=... (gitignored). Si clonas el repo en otra máquina, hay que volver a ponerla ahí.
